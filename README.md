# 语音合成便携版

这是一个基于 `edge-tts` 的 Windows 桌面语音合成工具，支持输入文字后一键生成 MP3，并提供试听与保存功能。

## 下载

- 最新发布版请前往 Releases：
  - [语音合成便携版 v1.0.0](https://github.com/Blakeee114/voice-synthesizer-portable/releases/tag/v1.0.0)
- 直接下载压缩包：
  - [voice-synthesizer-portable-v1.0.0.zip](https://github.com/Blakeee114/voice-synthesizer-portable/releases/download/v1.0.0/voice-synthesizer-portable-v1.0.0.zip)

## 功能

- 支持中英文语音合成
- 可调整语速
- 生成后可直接试听
- 支持保存为 MP3
- 便携版免安装，解压即可使用

## 使用方法

1. 下载并解压压缩包。
2. 双击 `语音合成.exe` 运行程序。
3. 输入要转换成语音的文字。
4. 选择语音和语速，点击“生成语音”。
5. 生成完成后可以先试听，再保存为 MP3。

## 注意事项

- 使用时需要联网，因为语音由在线服务生成。
- 如果 Windows 弹出安全提示，选择“更多信息”后继续运行即可。
- 如果被杀毒软件拦截，通常属于打包程序的常见误报。
